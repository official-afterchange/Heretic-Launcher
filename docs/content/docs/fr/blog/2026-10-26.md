Premier jour sur Heretic Launcher. Je pose les bases du projet.

## Ce que j'ai fait

- **Rédaction du README** du projet.
- **Mise en place de l'environnement de travail** pour utiliser Tauri v2.
- **Initialisation de Tauri** avec React et TypeScript pour le front, et Rust pour le back.
- **Création des premières pages** du launcher :
  - **Account** : la page de compte.
  - **Home** : la page d'accueil, c'est de là qu'on lance le jeu. On y voit aussi les informations du serveur auquel appartient le launcher.
  - **Info** : des informations sur le développeur (moi).
  - **Settings** : les paramètres.
