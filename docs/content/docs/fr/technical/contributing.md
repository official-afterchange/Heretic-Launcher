Merci de l'intérêt que vous portez au développement de **Heretic Launcher** ! Toute contribution est la bienvenue, qu'il s'agisse de corriger des bugs, d'améliorer la documentation ou de proposer de nouvelles fonctionnalités.

## Comment contribuer ?

### 1. Signaler un bug ou proposer une idée
Si vous rencontrez un problème ou si vous avez une suggestion :
* Ouvrez une [Issue sur GitHub](https://github.com/official-afterchange/heretic-launcher/issues) en décrivant clairement le problème ou la proposition.
* Fournissez des étapes pour reproduire le bug si possible (avec des logs ou des captures d'écran).

### 2. Proposer du code (Pull Requests)
1. **Forkez** le dépôt officiel.
2. Créez une branche pour votre fonctionnalité ou votre correction de bug :
   ```bash
   git checkout -b feature/ma-fonctionnalite
   ```
3. Effectuez vos modifications et commitez-les avec des messages clairs.
4. Poussez votre branche sur votre fork :
    ```bash
    git push origin feature/ma-fonctionnalite
    ```
5. Ouvrez une Pull Request (PR) sur le dépôt principal en expliquant clairement vos modifications.

## Configuration pour le développement
Pour lancer le projet en local afin de tester vos modifications, référez-vous au [guide d'installation](/en/technical/installation/).

Assurez-vous que votre code respecte la structure du projet (Tauri v2 / TypeScript / Rust) avant de soumettre votre Pull Request !
