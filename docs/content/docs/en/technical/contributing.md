Thank you for your interest in contributing to **Heretic Launcher**! All contributions are welcome, whether it's fixing bugs, improving documentation, or proposing new features.

## How to Contribute

### 1. Report a Bug or Suggest an Idea

If you encounter an issue or have a suggestion:

- Open an [Issue on GitHub](https://github.com/official-afterchange/heretic-launcher/issues) clearly describing the problem or proposal.
- Provide steps to reproduce the bug whenever possible, including logs or screenshots.

### 2. Submit Code (Pull Requests)

1. **Fork** the official repository.
2. Create a branch for your feature or bug fix:

   ```bash
   git checkout -b feature/my-feature
   ```

3. Make your changes and commit them with clear, descriptive commit messages.
4. Push your branch to your fork:

   ```bash
   git push origin feature/my-feature
   ```

5. Open a Pull Request (PR) against the main repository, clearly explaining your changes.

## Development Setup

To run the project locally and test your changes, refer to the [installation guide](/en/technical/installation/).

Make sure your code follows the project's architecture and conventions (Tauri v2 / TypeScript / Rust) before submitting your Pull Request!
