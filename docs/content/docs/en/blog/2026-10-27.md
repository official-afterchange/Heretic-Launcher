Setting up and configuring the official Heretic Launcher documentation using Astro and Starlight.

## What I did

- **Installed and configured Starlight** in the project to structure the documentation in a clean and professional way.
- **Set up multilingual support (i18n)** to handle both French and English.
- **Created the landing page (Splash page)** with a modern design and quick links to the various sections.
- **Wrote the first pages of technical documentation** :
  - **Installation**: to guide users through setting up the launcher.
  - **Architecture**: to explain how the Tauri backend and project structure work.
  - **Frontend**: to document the user interface developed with React and TypeScript.
  - **Build**: to explain the compilation process and the generation of executables.
  - **Contributing**: to formalize the rules and steps for contributing to the open-source project.
