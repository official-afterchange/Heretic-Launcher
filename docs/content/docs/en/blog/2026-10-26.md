First day on Heretic Launcher. I'm laying the groundwork for the project.

## What I did

- **Wrote the README** for the project.
- **Set up the development environment** to use Tauri v2.
- **Initialized Tauri** with React and TypeScript for the frontend, and Rust for the backend.
- **Created the first pages** of the launcher:
  - **Account**: the account page.
  - **Home**: the landing page, where you launch the game. It also shows information about the server the launcher belongs to.
  - **Info**: information about the developer (me).
  - **Settings**: the settings page.
