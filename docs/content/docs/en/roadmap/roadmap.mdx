## DevOps Loop (Continuous Lifecycle)

<Steps>

1. **Plan & Code**  
   Modular development (Rust for performance/system, Svelte for UI). Pre-commit hooks enforcement (`cargo fmt`, `prettier`, `clippy`).

2. **Build & Test (CI Pipeline)**  
   On every push to `main` or MR creation: automated execution of Rust unit tests, TypeScript/Svelte type validation, and Tauri compilation check.

3. **Release & Package (CD Pipeline)**  
   Automatic creation of installation artifacts whenever a version tag (e.g., `v0.1.0`) is pushed.

4. **Operate & Distribute**  
   Distribution of ready-to-use executables with full 100% offline mode support.

</Steps>
